# Hard Mode for Hackerss

Four arcade mini-games for Cybersecurity Awareness Month. Theme: "Don't Make It Easy for Them."

Open `index.html` to play.

## Adding your game

1. Put your game in `games/your-game.html`.
2. Link `../assets/brand.css` and `../assets/pixel.js`, and use only the colors in `C`.
3. Add a Menu link to `../index.html`.
4. In `index.html`, fill in your game's `name`, `blurb` and `href` in the `GAMES` list.
