🎯 THE REAL-WORLD LESSON

Security updates fix known flaws in software. Install security updates promptly, especially for your operating system, browser, and security software. Turn on automatic updates when available. In the game, missing patches activates extra exploit threats and makes breaches more damaging.

🧠 WHY THIS GAME TEACHES IT

Weapons and cooling fans = hardware investments. Patches = software fixes. You need both to survive the arcade, but buying hardware is never a substitute for closing a known software vulnerability. Short decision events cover official update sources, fake pop-ups, restarts, and unsupported devices.

Gameplay damage and enemy types are educational metaphors, not literal cybersecurity statistics. Cybersecurity Awareness Month theme: the four cybersecurity basics (2026). Content based on CISA: Update Software and NIST: Guide to Enterprise Patch Management. Entire game runs locally in this file.
